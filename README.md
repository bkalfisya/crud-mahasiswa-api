# CRUD Data Mahasiswa (PHP murni)

Proyek awal untuk tutorial "Membuat API dengan PHP Murni". Proyek ini BELUM punya API.

1. Salin folder `crud-mahasiswa` ke `C:\xampp\htdocs\`.
2. Jalankan Apache dan MySQL dari XAMPP Control Panel.
3. Buka `http://localhost/phpmyadmin`, tab Import, pilih `database.sql`, klik Go.
4. Buka `http://localhost/crud-mahasiswa/`.

Butuh PHP 8.1 atau lebih baru. Bila MySQL Anda memakai password, ubah `koneksi.php`.
Folder `bahan-tutorial/` berisi berkas pendukung yang dipakai di tengah tutorial.
